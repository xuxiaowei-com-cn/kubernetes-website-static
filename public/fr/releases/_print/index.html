Versions

  • 1: Notes

Le projet Kubernetes maintient des branches de versions pour les trois versions mineures les plus récentes (1.35, 1.34, 1.33). Kubernetes 1.19 et plus récent reçoivent environ 1 an de support de correctifs. Kubernetes 1.18 et plus ancien ont reçu environ 9 mois de support de correctifs.

Les versions de Kubernetes sont exprimées sous la forme x.y.z, où x est la version majeure, y est la version mineure et z est la version du correctif, selon la terminologie de Gestion sémantique de version.

Plus d'informations dans le document sur la politique en matière de version.
